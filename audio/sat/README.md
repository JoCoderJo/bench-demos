# demo/audio/sat — isolated letter sounds from ShowAndTellLetter.com

26 files, `a.mp3` … `z.mp3`: the "1 - Sound.mp3" track (the letter sound on its own, no letter name) from each
letter folder of `https://alphabet-sounds.showandtellletter.com/alphabet-sounds-a-z.zip` (set version October 2026,
pulled 2026-10-24). The set's own README: "free for home and classroom use". The site's Terms of Use
(https://www.showandtellletter.com/terms/) allow personal, classroom and home educational use and forbid
republishing or redistributing the content on another website and any commercial use.

So: fine on the family tablet (this project is a home project; see the README's licence policy), NOT for the public
demo site and NOT for anything sold. The Words/Sentence tracks were not copied — the word recordings in
`free/words/` cover that. Note `c` and `k` are the same clip (/k/), `q` is /kw/, `x` is /ks/, vowels are the short sounds.

Used by `tablet/apps/letters/build.py` as the second tier: a human recording in `human/` still wins; an approved
Commons recording (`free/approved.json`) is third.
